Expense Tracker & Spending Analytics

A Python-based expense tracking application that stores expenses in an SQLite database and provides spending analysis and visualization.

Features

- Add expenses
- View all expenses
- Delete expenses
- Calculate total spending
- Analyze category-wise spending
- Visualize spending using a bar chart
- SQLite database storage
- Menu-driven interface

Technologies Used

- Python
- SQLite
- Matplotlib

How to Run

1. Install Python.
2. Install Matplotlib:

pip install matplotlib

3. Run the application:

python expense_tracker.py

Project Structure

Expense_Tracker/
├── expense_tracker.py
├── README.md
└── .gitignore

The SQLite database file is excluded from GitHub using ".gitignore".

Learning Outcomes

- Python functions and control statements
- SQLite database operations
- SQL queries and aggregation
- Data analysis using "GROUP BY" and "SUM()"
- Data visualization using Matplotlib
- Basic project development and version control
